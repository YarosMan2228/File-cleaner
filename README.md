# File Cleaner

Наводит порядок на ноутбуке с Windows: находит мусор, дубликаты и лишнее, раскладывает файлы по папкам «по смыслу», сжимает то, что редко открывают. **Ничего из твоих файлов не удаляет без твоего подтверждения.**

```
скан → проверка → сортировка → утверждение удаления → сжатие
                                  ↑
                     папка «Ready for approval»: смотришь сам
```

## Как это устроено

| Этап | Что делает | Что с файлами |
|---|---|---|
| **Скан** | Индекс всех файлов в SQLite: размер, даты, откуда скачан (метка `Zone.Identifier`), облачный ли файл OneDrive | Только чтение |
| **Проверка** | Ищет мусор, дубли, распакованные архивы, лишние установщики, неподключённые диски виртуалок, старые большие файлы | Кэши и temp удаляются сразу, остальное переезжает в **Ready for approval** |
| **Сортировка** | Раскладывает Загрузки/Рабочий стол по **секторам** (Учёба, Работа…) и типам (Документы, Видео…) | Перемещение, программы не теряют файлы |
| **Утверждение** | Что ты перетащил в `_ВЕРНУТЬ` — возвращается на место, остальное удаляется | Удаление только здесь |
| **Сжатие** | Прозрачное сжатие Windows для «холодных» папок | Файлы на местах, открываются как обычно |

Любое действие, кроме утверждения удаления, отменяется командой `undo`.

### Что считается ненужным

Решаешь ты: правила лежат в `rules.toml` (`filecleaner rules --edit`). У каждого правила режим:

- `delete` — удалить сразу. Разрешено **только** для того, что восстанавливается само: кэши браузеров и программ, временные файлы Windows, `Thumbs.db`, пустые папки.
- `review` — перенести в **Ready for approval**: дубликаты с именем-копией или лишние в Загрузках, распакованные архивы, установщики уже установленных программ и старые версии установщиков, недокачанные файлы, неподключённые диски VirtualBox.
- `report` — только в отчёт: копии в разных «осмысленных» папках (может, так задумано), **старые большие файлы** (возраст ≠ ненужность), остальные установщики.
- `off` — не искать.

Файлы со словами вроде «паспорт», «договор», «диплом», «license» в имени и папки из `[protect] paths` всегда только в отчёте.

### Дубликаты: какой оставить

Сравнивается содержимое (размер → хэш начала и конца → полный хэш), жёсткие ссылки дублями не считаются. Остаётся файл **без** «(1)»/«копия» в имени, лежащий **не** в Загрузках/на Рабочем столе, **самый ранний** по дате создания. Одинаковые папки целиком («Проект» и «Проект (2)») находятся тоже.

### Папка Ready for approval

Лежит на том же диске, что и файлы (`~\Ready for approval`, `B:\Ready for approval`), поэтому перенос мгновенный. Внутри — подпапки по причинам («Дубликаты - имя-копия», «Распакованные архивы»…), с сохранением пути, откуда файл, и `ОТЧЁТ.html` с объяснением для каждого файла.

1. Смотришь в Проводнике.
2. Нужное перетаскиваешь в `_ВЕРНУТЬ` (можно папками) или просто забираешь куда хочешь.
3. `filecleaner approve` — из `_ВЕРНУТЬ` всё вернётся на прежние места, остальное удалится.

### Чтобы программы не потеряли файлы

Перед сортировкой программа смотрит, какие программы помнят пути к файлам: реестр `HKCU` и их настройки в `AppData`. Например, проекты CapCut, DaVinci Resolve, недавние файлы VS Code.

- Если файл помнит программа — на старом месте остаётся **ссылка** (символьная ссылка для файла, junction для папки), программа открывает файл как раньше.
- «Недавние документы» Word/Excel/PowerPoint и ярлыки (Рабочий стол, Пуск, недавние файлы Windows) переписываются на новый путь.
- Папки, в которые пишут программы (`Telegram Desktop`), не трогаются (`[sort] keep_folders`).

### Сжатие

`compact /exe:LZX` — сжатие NTFS, которое Windows распаковывает на лету. Файлы остаются там же, пути не меняются. Сжимаются только файлы, которые реально становятся меньше (оценка по выборке): текст, логи, программы, базы. Уже сжатые форматы (zip, jpg, mp4, docx, pdf) пропускаются. Диски виртуалок — только если явно разрешить.

### Приступай: всё за один раз (можно на ночь)

Первый пункт меню. Одно подтверждение — дальше можно уйти:

1. Мусор и копии ищутся на **всех встроенных дисках**. Windows, программы (в том числе установленные прямо в корень диска), игры и проекты не трогаются; на системном диске вне папки пользователя (`C:\Siemens`, `C:\GMSProjects`…) — только отчёт.
2. Кэши и временные файлы удаляются сразу.
3. **Проверенное в папках-свалках** (`[scan] dump_folders`: Загрузки, Рабочий стол…) удаляется сразу: копия ещё раз сравнивается с оригиналом байт в байт, распакованный zip — с папкой по контрольным суммам каждого файла. Не сошлось, архив не zip, оригинал тоже на удалении — ждёт утра.
4. Всё остальное — в **Ready for approval**, утром решаешь сам.
5. Раскладываются папки из `[night] sort_folders`. Подпапки переносятся только в свалках: в Документах живут папки программ (Zoom, MATLAB, Visual Studio), там — только отдельные файлы. Папку с программой (много `.dll`) программа не раскладывает.
6. Отчёт `ночь.html`, журнал в `%LOCALAPPDATA%\FileCleaner\logs\`, потом — сон или выключение (`[night] after`).

Пока идёт работа, Windows не уснёт. Всё считается на этом компьютере: ИИ работает только с моделью по адресу `localhost`/`127.0.0.1` и в обход системного прокси — другой адрес в `[ai] url` программа не использует.

```
python -m filecleaner night                  # что будет сделано (ничего не трогает)
python -m filecleaner night --apply          # приступить
python -m filecleaner night --apply --yes --after sleep   # без вопросов, в конце — сон
```

**Каждую ночь сам:** «Настройки» → «Приступай» → «Запускать сам каждую ночь», или
`filecleaner schedule --at 03:00` (`--no-wake` — не будить компьютер, `--off` — выключить).
Это задача «File Cleaner - Night» в Планировщике Windows для текущего пользователя, без прав администратора.
От батареи не запускается, а пропущенный запуск днём не догоняет, чтобы файлы не переезжали, пока ты работаешь.
Чтобы компьютер просыпался сам, в Windows должны быть разрешены таймеры пробуждения.

### Локальная ИИ-модель (по желанию)

Для файлов, которые не попали ни в один сектор по правилам, программа может спросить локальную модель через [Ollama](https://ollama.com). Всё считается на твоём компьютере, в интернет ничего не уходит. Модель видит имя файла, сайт-источник и начало текста (txt, docx, pptx, xlsx).

```
setx OLLAMA_MODELS "B:\Ollama\models"     # по желанию: модели (~5 ГБ) на другом диске, а не на C:
winget install Ollama.Ollama
ollama pull qwen2.5:7b
```

Потом в правилах: `[ai] enabled = true`. Ответы запоминаются — второй запуск быстрый.
Готова ли модель, показывает `filecleaner rules`. Для `qwen2.5:7b` хватает видеокарты с 6 ГБ памяти.

## Установка и запуск

Нужен Python 3.11+ (сторонние библиотеки не нужны).

```
git clone https://github.com/YarosMan2228/File-cleaner.git
cd File-cleaner
```

- **Двойной клик по `File Cleaner.cmd`** — окно программы: «Посмотреть, что будет» → «Приступить»,
  решения по отложенному кнопками «Удалить» / «Вернуть на место» (перетаскивать ничего не нужно),
  история с отменой. Окно — это Microsoft Edge без адресной строки, данные — с маленького сервера
  на этом же компьютере (слушает только 127.0.0.1, доступ по секретному токену). Или `python -m filecleaner gui`.
  Язык окна — русский или английский: «Настройки» → «Язык программы» (или `[ui] language` в правилах;
  `auto` — как в Windows). По-английски называются и папки при сортировке: Documents, Images…
- **Двойной клик по `filecleaner.bat`** — меню на русском в консоли.
- Или из терминала:

```
python -m filecleaner night --apply        # приступай: всё за один раз, можно на ночь
python -m filecleaner schedule --at 03:00  # приступай каждую ночь в 03:00
python -m filecleaner scan                 # что занимает место
python -m filecleaner check                # что лишнее (только показать)
python -m filecleaner check --apply        # кэши удалить, остальное → Ready for approval
python -m filecleaner approve              # утвердить удаление
python -m filecleaner sort                 # план сортировки Загрузок
python -m filecleaner sort "D:\Папка" --apply
python -m filecleaner compress "C:\Users\...\Documents\Архив" --apply
python -m filecleaner history
python -m filecleaner undo                 # отменить последнее действие
python -m filecleaner rules --edit         # правила: что считать ненужным, секторы
```

Без `--apply` любая команда только показывает план и сохраняет HTML-отчёт.

### Сборка программы: .exe и установщик

```
pip install pyinstaller
python packaging/build.py
```

В `dist/` появятся:
- `FileCleaner/` — готовая программа без Python: `File Cleaner.exe` (окно) и `filecleaner.exe` (команды);
- `FileCleaner-<версия>-portable.zip` — та же папка одним архивом;
- `FileCleaner-<версия>-setup.exe` — установщик, если есть Inno Setup 6 (`winget install JRSoftware.InnoSetup`).

Установщик ставит программу только для текущего пользователя, права администратора не нужны.
Правила, журнал и кэш ИИ лежат в `%LOCALAPPDATA%\FileCleaner` и при удалении программы остаются.

Лицензионное соглашение — `LICENSE.txt` (установщик показывает его перед установкой);
лицензии сторонних компонентов (Python, pypdf, PyInstaller) сборка собирает в `THIRD-PARTY-NOTICES.txt`.
Подпись программы и установщика — если задан сертификат, см. [docs/SIGNING.md](docs/SIGNING.md).

## Где что лежит

- `%LOCALAPPDATA%\FileCleaner\index.db` — индекс и хэши (повторный скан быстрый).
- `%LOCALAPPDATA%\FileCleaner\journal\` — журнал всех действий, по нему работает `undo`.
- `%LOCALAPPDATA%\FileCleaner\reports\` — HTML-отчёты.
- `%LOCALAPPDATA%\FileCleaner\rules.toml` — твои правила.

## Чего программа не трогает никогда

Windows, Program Files, ProgramData, AppData (кроме известных кэшей), папки проектов (`.git`, `package.json`, `.sln`…) и программ (есть `.dll`) — по одному файлу; игры (Steam, Epic…), облачные файлы OneDrive, которых нет на диске (чтение запустило бы скачивание), файлы, изменённые последние 30 минут.
