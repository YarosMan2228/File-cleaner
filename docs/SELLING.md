# Как продавать File Cleaner

## Как устроена лицензия

- **30 дней пробного периода** с первого запуска: работает всё.
- Потом без ключа можно смотреть, что будет сделано, историю, отменять и возвращать файлы на место.
  Чистить, раскладывать и удалять нельзя: окно показывает «Нужен ключ», ночной запуск записывает причину
  в `logs\night-errors.log`.
- **Ключ** `FC1-…` — это имя покупателя и дата, подписанные твоим закрытым ключом (Ed25519).
  Программа проверяет подпись открытым ключом у себя, без интернета.
- Покупатель вводит ключ в «Настройки» → «Лицензия» → «Активировать» или командой `filecleaner license FC1-…`.
  Ключ хранится в `%LOCALAPPDATA%\FileCleaner\license.json`.

## Закрытый ключ

Он создан командой `python packaging/keygen.py init` и лежит в
`%USERPROFILE%\.filecleaner-seller\license-signing.key`. Это вне репозитория, в git он не попадёт.

- **Сделай копию**: на флешку или в менеджер паролей. Если ключ потеряется, выданные ключи продолжат работать,
  но новых для уже вышедших версий не сделать.
- **Никому не показывай.** Если он утечёт, ключи сможет выпускать кто угодно. Тогда удали старый, сделай `init` заново,
  выпусти новую версию и перешли покупателям новые ключи (все выданные — в `issued.csv` рядом с закрытым).

## Магазин

Проще всего работать с площадкой, которая сама продаёт покупателю (merchant of record). Она принимает оплату
картами, считает и платит НДС и налоги с продаж в разных странах и выдаёт чеки. Такие площадки —
Lemon Squeezy, Paddle, Gumroad. Условия и комиссии меняются, сверь их на сайтах площадок.

1. Заведи товар «File Cleaner» и приложи установщик (или дай ссылку на выпуск).
2. Ссылку на страницу товара впиши в `BUY_URL` в `filecleaner/licensing.py`. Тогда в окне появится кнопка «Купить ключ».
3. Выдавай ключи одним из способов:
   - **Вручную** (для начала). После продажи выполни `python packaging/keygen.py issue "Имя или почта покупателя"`
     и отправь ключ письмом.
   - **Списком.** `python packaging/keygen.py batch 100` делает 100 ключей «License #0001…» одним файлом.
     Подходит, если магазин умеет выдавать каждому покупателю код из загруженного списка.
   - **Автоматически.** Вебхук магазина о продаже вызывает маленькую функцию (например, в Cloudflare Workers),
     та подписывает ключ (`licensing.issue`) и отправляет письмо. Закрытый ключ тогда хранится в секретах функции.

У Gumroad и Lemon Squeezy есть и свои ключи лицензий, но их проверяют через интернет, по API площадки.
Программа их не примет: она проверяет только свои ключи `FC1-…`, без сети.

## Перед первой продажей

- [ ] **Сертификат подписи кода** ([SIGNING.md](SIGNING.md)). Без него Windows SmartScreen пугает покупателей.
- [ ] **Юрист** посмотрел `LICENSE.txt`. На странице магазина есть условия и политика конфиденциальности.
- [ ] `BUY_URL` задан (`packaging/release.py` предупредит, если нет).
- [ ] **Репозиторий с исходниками — приватный.** Сейчас он публичный, и кто угодно может собрать программу
  без проверки ключа. Проверка обновлений читает выпуски из `REPO` в `filecleaner/update.py`.
  Для приватных исходников заведи отдельный публичный репозиторий только для выпусков
  (например, `File-cleaner-releases`) и впиши его в `REPO`; `release.py` выпустит туда.
- [ ] Версия поднята, в `CHANGELOG.md` описано, что нового; программа собрана и выпущена (README → «Обновления»).
- [ ] Есть копия закрытого ключа.
