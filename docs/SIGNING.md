# Подпись программы

Без подписи Windows SmartScreen при первом запуске установщика покажет «Windows защитила ваш
компьютер — неизвестный издатель». Подпись говорит Windows, кто выпустил программу, и что файл
не изменили после сборки.

## Где взять сертификат

| Вариант | Цена (ориентир) | Кому подходит |
|---|---|---|
| Microsoft Trusted Signing (Azure) | ≈ $10 в месяц | Организациям и — не во всех странах — частным разработчикам; уточни условия на сайте Microsoft. Подпись в облаке. |
| OV-сертификат (Sectigo, SSL.com, Certum…) | ≈ $200–500 в год | Частным лицам и компаниям. С 2023 года ключ хранится на токене или в облачном HSM. |
| EV-сертификат | ≈ $300–700 в год | Только компаниям, проверка строже. Как SmartScreen относится к нему сейчас — уточни у продавца. |

Цены и условия меняются — перед покупкой проверь их у продавца.

Проверка личности или компании занимает от нескольких дней до пары недель. SmartScreen доверяет
новому сертификату не сразу: «репутация» копится по мере того, как программу скачивают и запускают.

## Как подписать сборку

`python packaging/build.py` подписывает `File Cleaner.exe`, `filecleaner.exe`, установщик и
деинсталлятор, если задан сертификат (иначе собирает без подписи и пишет об этом):

```powershell
# сертификат в файле (.pfx):
$env:FILECLEANER_SIGN_PFX = "C:\ключи\filecleaner.pfx"
$env:FILECLEANER_SIGN_PASSWORD = "пароль от pfx"
# или сертификат в хранилище Windows (токен, установленный сертификат):
$env:FILECLEANER_SIGN_THUMBPRINT = "отпечаток сертификата"

python packaging/build.py
```

Метка времени ставится через `http://timestamp.digicert.com` — подпись остаётся действительной
и после истечения сертификата. Другой сервер: `FILECLEANER_SIGN_TIMESTAMP`, пустое значение — без метки.

Подписывает `packaging/sign.ps1` (встроенная в Windows команда `Set-AuthenticodeSignature`,
Windows SDK не нужен). Для облачной подписи (Artifact Signing, облачный HSM) нужен `signtool` из
Windows SDK с библиотекой поставщика — замени вызов в `sign.ps1` по инструкции поставщика.

Проверить подпись: Проводник → Свойства файла → «Цифровые подписи», или

```powershell
Get-AuthenticodeSignature "dist\FileCleaner\File Cleaner.exe" | Format-List
```

Пароль и файл сертификата не кладутся в репозиторий.
